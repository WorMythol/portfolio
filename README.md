# Сайт-портфолио

Статичный сайт: `index.html`, `style.css`, `main.js`, `config.js`, картинки в `img/` (всего ~0,7 МБ). Ничего собирать не нужно, просто открой `index.html` в браузере.

## 1. Впиши свои данные

Открой `config.js` и заполни: имя, Telegram (ник без @), ссылку на MAX, телефон, почту. Пустые поля не показываются на сайте.

Форма заявки:
- если пусто `formEndpoint`, кнопка «Отправить» копирует текст заявки и открывает твой Telegram (или почту);
- чтобы заявки приходили на почту сами, зарегистрируйся на https://formspree.io (бесплатно до 50 заявок в месяц), создай форму и вставь её адрес вида `https://formspree.io/f/xxxxxx` в `formEndpoint`.

## 2. Выложи в интернет бесплатно

**Вариант А: Vercel (проще всего, у тебя уже есть аккаунт с Happy Kids)**
1. Зайди на https://vercel.com/new.
2. Внизу выбери загрузку папки (или «Deploy» через GitHub, см. вариант Б) и перетащи папку `portfolio-site`.
3. Получишь адрес вида `имя.vercel.app`. В настройках проекта (Settings → Domains) можно поменять имя.

**Вариант Б: GitHub Pages**
1. Создай на GitHub публичный репозиторий, например `portfolio`.
2. Загрузи туда файлы из этой папки (Add file → Upload files).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/root` → Save.
4. Через минуту сайт будет на `https://WorMythol.github.io/portfolio/`.

Свой домен `.ru` стоит ~200–300 ₽ в год (reg.ru, nic.ru), его можно подключить к любому варианту позже.

## 3. Где использовать ссылку

Kwork, FL.ru, Профи.ру, Авито: в профиле «О себе» и в каждом отклике строкой «Портфолио: <ссылка>». Ещё в описании Telegram и MAX.

## Что не выкладывать

В папке нет `.env`, токенов и боевых данных. Все скриншоты сняты на демо-данных. Не добавляй сюда исходники проектов.
